# KeepStreak

의지를 숫자로 남기는 습관 챌린지 앱입니다. 매일 지켜낸 날을 연속 기록으로 보여주며 꾸준함을 만들어 줍니다.

## 주요 기능

- **연속 일수 자동 추적** — 매일 자동으로 하루가 쌓입니다.
- **홈 화면 위젯** — 대표 챌린지를 앱을 켜지 않고도 확인합니다.
- **실패 시 리셋** — 어긴 날만 리셋해 1일부터 다시 시작합니다.

## 자주 묻는 질문

**Q. 매일 체크를 해야 하나요?**
아니요. "안 하기"를 지키는 챌린지이므로 매일 자동으로 연속 일수가 올라갑니다. 실패한 날에만 리셋 버튼을 눌러 주세요.

**Q. 앱을 며칠 안 열면 기록이 멈추나요?**
아니요. 연속 일수는 시작일 기준으로 계산되어, 다시 열면 정확한 값으로 보정됩니다.

**Q. 데이터는 어디에 저장되나요?**
챌린지 이름과 기록은 기기에만 저장됩니다. 서버로 전송되지 않습니다.
