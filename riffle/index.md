# Riffle 고객지원

Riffle은 곡이 시작되기 전에 노래 제목을 음성으로 읽어주는 iPhone 음악 플레이어입니다. 한 번 섞은 재생목록은 그대로 유지되며, 다른 순서로 다시 듣고 싶다면 보관함 화면에서 아래로 당겨 새로고침해 주세요.

## 걷기·러닝 동반자

설정에서 걷기·러닝을 켜면 음악을 끊지 않고 거리·페이스·시간을 곁들여 안내합니다(기본 꺼짐). GPS는 쓰지 않으며, Apple Watch가 있으면 워치가, 없으면 아이폰 모션 센서가 측정합니다. 운동을 종료해도 음악은 계속 재생됩니다. 안내 항목(거리·페이스·시간)은 설정에서 개별로 끄거나 켤 수 있습니다.

## 자주 묻는 질문 (FAQ)

### 걸을 때 Apple Watch에서 Riffle이 자꾸 화면에 떠요.

Riffle의 문제가 아니라 **Apple Watch의 시스템 설정** 때문입니다. 워치가 "손목을 올리면 마지막에 쓰던 앱을 다시 열도록" 설정돼 있으면, 걸을 때 손목이 자주 올라가면서 마지막에 열었던 앱(Riffle)이 계속 나타납니다.

해결 방법 — 손목을 올릴 때 앱 대신 **시계 화면**으로 돌아가도록 바꿔 주세요:

- **Apple Watch에서**: 설정 → 일반 → **시계로 돌아가기** → **항상** 선택
- **또는 iPhone에서**: Watch 앱 → 나의 워치 → 일반 → **시계로 돌아가기** → **항상**

이렇게 하면 손목을 올려도 시계로 돌아가고, 원할 때만 Riffle을 열 수 있습니다. (Apple Watch의 기본 동작은 시계로 돌아가는 것이라, 대부분의 경우 이 설정을 바꿀 필요가 없습니다.)
